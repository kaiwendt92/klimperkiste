Kindermodus

Die App verhindert bereits Zoomen, Scrollen und langes Drücken. Damit dein Kind die App gar nicht verlassen kann, nutze zusätzlich die Sperre des Geräts:

iPad / iPhone: „Geführter Zugriff“
  1. Einstellungen → Bedienungshilfen → Geführter Zugriff → einschalten und Code festlegen.
  2. Klimperkiste öffnen und die Seitentaste (bzw. Home-Taste) 3× schnell drücken → „Starten“.
  3. Beenden: wieder 3× drücken und Code eingeben.
Android: „App anheften“
  1. Einstellungen → Sicherheit → App anheften (Bildschirm fixieren) → einschalten.
  2. Übersicht der geöffneten Apps öffnen → auf das App-Symbol tippen → „Anheften“.
  3. Lösen: „Zurück“ und „Übersicht“ gleichzeitig gedrückt halten.

Als App installieren

iPad / iPhone (Safari): Teilen-Symbol → „Zum Home-Bildschirm“.
Android (Chrome): Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.
